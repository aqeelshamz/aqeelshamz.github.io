Aqeel Shamsudheen: solo product builder from Thrissur, Kerala

Aqeel Shamsudheen (aqeelshamz) is a solo product builder and indie SaaS founder from Thrissur, Kerala, India. What is Wixzel Voice?

Wixzel Voice (voice.wixzel.com) is a voice AI API built solo by Aqeel Shamsudheen. Developers use it to build AI agents that place and answer real phone calls over their own SIP trunk, or talk to users in web and mobile apps. One API key and one prepaid balance cover every voice engine, billed per second. It ships as an HTTP API, a hosted MCP server, and SDKs on npm (wixzel-voice) and pub.dev (wixzel_voice).
